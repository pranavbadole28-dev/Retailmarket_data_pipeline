# 🛒 Retail Sales Data Engineering Pipeline

A beginner-friendly Data Engineering project demonstrating an end-to-end **ETL (Extract, Transform, Load) pipeline** using **Python, Pandas, NumPy, SQLite, and SQL**.

The project simulates a retail sales workflow where raw CSV data is ingested, cleaned, transformed, stored in a SQLite database, and queried to generate business insights.

## 🔄 Pipeline Workflow

```text
CSV Files
    ↓
Data Ingestion
    ↓
Data Cleaning & Validation
    ↓
Data Transformation
    ↓
SQLite Database
    ↓
SQL Queries
    ↓
Business Insights
